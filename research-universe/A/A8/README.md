# A8 — From Knowing to Doing

*Tool Access, Execution, and Evidence in Artificial Agency*

**Status:** Public preprint · **Edition:** v1.8 · **Author:** Zawwar Sami

Knowing how a tool works is different from having authorized access, successfully invoking it, changing an external system, and independently verifying what happened. This paper proposes an inspectable action-evidence chain.
