# A7 — Operational Will

*Commitment, Initiative, and the Question of What an Agent Does Next*

**Status:** Public preprint · **Edition:** v1.8 · **Author:** Zawwar Sami

An agent can retain a commitment without ever returning to it. This paper explores the separation between remembering obligations and being able to reconsider and act on them within a defined authority.
